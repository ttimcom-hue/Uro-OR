# 癌症討論會追蹤表：開發說明（給 Claude Code / 新對話看）

每週四 GU 癌症討論會（Combined Conference: GU & Radiology & Nephrology）的名單整理工具。
主要挑黃冠華部長要開的達文西、腎切等重大癌症手術病人，追蹤：還沒討論／已討論／結論／會後待辦／已開刀。

## 資料在哪裡
- **病人資料只存在 Google 試算表「黃部長 癌症討論會追蹤表」**（ID 寫在根目錄 `Code.gs` 的 `CANCER_ID`）。
- 這個 repo 是公開的，**只放程式與說明，絕對不要 commit 病人姓名、病歷號、病情或刀表原始檔**。
  測試用刀表一律用 `sample-or.txt` 這種假資料。
- 試算表的分頁結構、公式、格式全部由 `CancerSheet.gs` 產生。要改結構：改 `CancerSheet.gs` →
  貼到 Apps Script 專案（跟 `Code.gs` 同一個專案）→ 執行 `setupCancerSheet()`。
  它只重寫公式與格式，不會刪使用者填的資料（細節見檔案開頭註解）。

## 檔案
| 檔案 | 內容 |
|---|---|
| `CancerSheet.gs` | `setupCancerSheet()`：建立／修復所有分頁、公式、下拉選單、條件格式 |
| `parse.js` | 用 JS 重現「刀表解析」的規則，`node cancer/parse.js cancer/sample-or.txt` 可測試 |

## 分頁（順序固定）
| 分頁 | 類型 | 說明 |
|---|---|---|
| 個案追蹤 | **資料（人工輸入）** | 每位病人一列。A–Q 欄見下表。G、H 是公式 |
| 會後待辦 | 公式 | **交班用**。已討論但未開刀（已討論-待手術／暫緩/改期／待確認）一人一列，依手術日排序。A3:K30 連結到交班 Google 文件 |
| 已討論個案 | 公式 | 討論日 ≤ 今天的個案，新到舊；上方統計 |
| 週會名單 | 公式 | B1 填討論會日期（人工），A6 起列出該日排入的病人 |
| 待討論清單 | 公式 | 狀態＝待討論，依手術日排序，含最晚討論日與提醒 |
| 刀表候選 | 公式 | B2 主刀、B3 關鍵字（人工可改）；列出刀表中符合的重大手術，用病歷號比對是否已在追蹤表 |
| 刀表匯入 | 原始資料 | A2 起貼 HIS 刀表文字（一欄一列） |
| 刀表解析 | 公式（後台） | 解析刀表，最多 400 筆 |
| 說明 | 文字 | 使用說明 |

## 刀表格式（HIS「手術工作表」複製出來的文字）
一個欄位一行。每筆手術從 8 位數病歷號開始，欄位順序：
病歷號、姓名、床號、手術日、時、手術師、癌、手術位置、手術名稱、特殊器械、來源、送單日、送單時、麻醉、預估失血、ASA、科別、刀別。
- **空欄位會變成兩行空白，有值只佔一行**（床號、癌、ASA 都會遇到）。所以：
  - 手術日在病歷號後第 3 行（有床號）或第 4 行（沒床號）；手術日是民國 7 位數，如 `1151208`
  - 手術日後：時（`08:30` 或 `TF:1`）、手術師
  - 手術師後一行是 `Y` → 有癌症註記，手術位置在手術日 +4；否則 +5
  - 手術名稱在手術位置下一行，來源（住/門/徑/急）在手術名稱後第 2 行
- 名字有時被截斷（例：只剩兩個字），比對一律用病歷號。
- 重大手術關鍵字（刀表候選 B3，可改）：
  `(?i)davinci|prostatectomy|nephr\w*ectomy|nephrouret|\bRNU\b|cystectomy|RARC|adrenal|thrombect|retroperitoneal`

## 使用流程
1. 新刀表 → 貼到「刀表匯入」A2（或調度板匯入）→「刀表候選」看「新個案」→ 複製 B–E 到「個案追蹤」，狀態「待討論」
2. 排進討論會 → 填 F 討論會日期，狀態「已排入」（同時準備「給放射科」檔）
3. 討論完 → 填 K 結論、M 報告醫師、O–Q 會後待辦，狀態「已討論-待手術」
4. 開完刀 → 狀態「已開刀」，填 L 術後病理（會自動從會後待辦消失）

## 修改注意
- 試算表 locale 是 zh_TW、時區 Asia/Taipei。公式用 Google Sheets 語法（LET、HSTACK、CHOOSECOLS、FILTER、REGEXMATCH）。
- 逐列複製的公式要用絕對參照（`$E$2:$E`），否則往下複製時範圍會跟著位移。
- 同一欄不要上下疊兩個會溢出（spill）的公式，下面那個會 `#REF!`／`#SPILL!`。
- 改了刀表解析規則，先改 `parse.js` 用 `sample-or.txt` 測，再改 `CancerSheet.gs` 的對應公式。
